# openobc-app-releases

Binary releases of the **OpenOBC** mobile application (Android APK).

- The application is **proprietary** — see [LICENSE](LICENSE). Its source code is **not** in this repository; development happens in the private `openobc-app` repository.
- **Stable** releases: `vX.Y.Z` tags. **Beta** releases: `vX.Y.Z-beta.N` tags, marked as pre-releases.
- Install: download the APK from a release page and allow "Install unknown apps" for your browser/file manager.
- Third-party open-source components bundled in the app are listed in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
